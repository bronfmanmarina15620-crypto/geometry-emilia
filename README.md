# גיאומטריה של אמיליה

אפליקציית תרגול גיאומטריה לטלפון (עברית, RTL) לכיתות ד׳–ו׳ — מיון משולשים לפי **זוויות** (חד / ישר / קהה) ולפי **צלעות** (שווה צלעות / שווה שוקיים / שונה צלעות), עם איורים SVG.

## איך לפתוח

1. פתחו את הקובץ `index.html` בדפדפן (כרום / ספארי בטלפון או במחשב).
2. אפשר גם להגיש את התיקייה כאתר סטטי (למשל `python3 -m http.server` מתוך `/workspace/geometry` ואז לפתוח `http://localhost:8000`).
3. אין שלב build ואין תלויות חיצוניות — הכל בקובץ HTML אחד.

## מה יש באפליקציה

- סשן של **15 שאלות** אמריקאיות בכל פעם
- בכל סשן חדש נשלפת **חבילה אקראית חדשה** ממאגר גדול (70+ שאלות)
- מסך הורים מאחורי קוד **PIN: `2604`**
- דוח לוואטסאפ + העתקה ללוח
- שמירת התקדמות ב־`localStorage` תחת המפתח `geometry_emilia_v1` (מקומי בלבד, בלי ענן ב־v1)
