# גיאומטריה של אמיליה

אפליקציית תרגול גיאומטריה לטלפון (עברית, RTL) לכיתות ד׳–ו׳ — **משולשים** (מיון לפי זוויות וצלעות) ו**מרובעים** (ריבוע, מלבן, מעוין, מקבילית, טרפז: זיהוי, צלעות מקבילות, סמוכות ונגדיות, תכונות, מי הוא גם מי), עם איורים SVG. במסך הבית בוחרים: משולשים / מרובעים / הכול מעורב.

## איך לפתוח

1. פתחו את הקובץ `index.html` בדפדפן (כרום / ספארי בטלפון או במחשב).
2. אפשר גם להגיש את התיקייה כאתר סטטי (למשל `python3 -m http.server` מתוך `/workspace/geometry` ואז לפתוח `http://localhost:8000`).
3. אין שלב build ואין תלויות חיצוניות — הכל בקובץ HTML אחד.

## מה יש באפליקציה

- סשן של **15 שאלות** אמריקאיות בכל פעם
- עד 3 ניסיונות לשאלה, בלי לחשוף את התשובה; אחרי שנגמרים הניסיונות — «כדאי לשאול את אמא או את המורה», ורשימת «תרגילים לשאול עליהם» בסוף הסשן
- מעקב לכל שאלה (בחירות, ניסיונות, זמן, תוצאה) ומסך הורים עם דירוג סוגי תרגילים והצעות למחר
- בכל סשן חדש נשלפת **חבילה אקראית חדשה** ממאגר גדול (70 שאלות משולשים + 72 מרובעים)
- מסך הורים מאחורי קוד **PIN: `2604`**
- דוח לוואטסאפ + העתקה ללוח
- שמירת התקדמות ב־`localStorage` תחת המפתח `geometry_emilia_v1` (מקומי בלבד, בלי ענן ב־v1)
